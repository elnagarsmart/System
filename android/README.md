# CardMaster Android

تطبيق Android مستقل عن موقع CardMaster وعن مشروع Academia.

## الوظيفة الحالية
- اكتشاف وجود NFC في الهاتف.
- استقبال اكتشاف الشريحة باستخدام Android Reader Mode.
- عرض أسماء تقنيات NFC التي يعلن عنها النظام (مثل NfcA وIsoDep وNfcV).
- عرض خصائص NDEF العامة عند توفرها، دون قراءة محتوى الرسائل.
- لا يرسل أوامر APDU أو أوامر خاصة بالعدادات، ولا يحاول تجاوز مفاتيح أو حماية البطاقات.

## البناء
افتح مجلد `android` في Android Studio حديث مع JDK 17، ثم انتظر مزامنة Gradle واختر:
**Build > Build Bundle(s) / APK(s) > Build APK(s)**

الحد الأدنى Android 6.0 (API 23). يتطلب الاختبار هاتفًا فعليًا يدعم NFC؛ المحاكي لا يختبر قراءة البطاقات الحقيقية.

## ملاحظات
- ظهور تقنية مثل IsoDep لا يعني أن محتوى البطاقة متاح أو أن التطبيق يعرف بروتوكولها.
- بطاقات الكهرباء قد تستخدم تطبيقًا/بروتوكولًا مغلقًا أو بيانات محمية. هذا التطبيق لا يقرأ الرصيد أو بيانات الشحن.
- لا يتم حفظ UID أو محتوى البطاقة أو رفعه إلى الإنترنت.
