# CardMaster Android

تطبيق Android مستقل عن موقع CardMaster وعن مشروع Academia.

## ما الذي يقدمه الإصدار 1.1.0؟
- واجهة عربية RTL بتصميم داكن وهوية بنفسجية خاصة بالتطبيق.
- أيقونة إطلاق مخصصة لـCardMaster.
- تشغيل وإيقاف Android NFC Reader Mode.
- اكتشاف تقنيات NFC التي يعلن عنها النظام، مثل NfcA وNfcB وNfcF وNfcV وIsoDep وNdef.
- فحص خصائص NDEF العامة فقط: هل الواجهة متاحة، السعة المعلنة، وإمكانية الكتابة المعلنة.
- سجل محلي لآخر 20 فحصًا، ويخزن الوقت وأسماء التقنيات وملخص NDEF فقط.
- إعداد تشغيل/إيقاف الاهتزاز بعد اكتشاف البطاقة.
- نسخ تقرير تشخيص عام أو مشاركته، دون رقم البطاقة أو محتواها.
- صفحة معلومات الجهاز وحالة NFC ودليل مختصر للتقنيات.

## البناء والتنزيل
يمكن بناء APK تجريبي من GitHub Actions:
1. افتح تبويب Actions في مستودع CardMaster.
2. افتح أحدث عملية Android debug build بعد اكتمالها بنجاح.
3. نزّل ملف cardmaster-android-debug من قسم Artifacts.
4. فك ملف ZIP وثبّت app-debug.apk على جهاز Android.

يمكن أيضًا فتح مجلد android في Android Studio حديث مع JDK 17 واختيار:
Build > Build Bundle(s) / APK(s) > Build APK(s)

الحد الأدنى Android 6.0 (API 23). يلزم هاتف فعلي يدعم NFC لاختبار قراءة البطاقات.

## حدود القراءة والخصوصية
- ظهور تقنية مثل IsoDep أو MIFARE لا يعني أن محتوى البطاقة متاح أو أن التطبيق يعرف بروتوكولها.
- التطبيق لا يقرأ رسائل NDEF، ولا يرسل APDU أو أوامر خاصة بالعدادات، ولا يحاول الوصول إلى بيانات الدفع أو الرصيد أو الشحن أو مفاتيح الحماية.
- بطاقات الكهرباء قد تستخدم تطبيقًا أو بروتوكولًا مغلقًا أو بيانات محمية؛ ظهور التقنية لا يتيح قراءة هذه البيانات.
- لا يتم حفظ UID أو محتوى البطاقة أو رفعه إلى الإنترنت.
- السجل المحلي قابل للمسح من شاشة السجل أو الإعدادات.
