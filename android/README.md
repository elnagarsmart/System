# CardMaster Android

تطبيق Android أصلي مستقل عن موقع CardMaster وعن مشروع Academia.

## الوظائف
- واجهة عربية RTL بهوية CardMaster البنفسجية.
- أيقونة إطلاق مخصصة.
- Android NFC Reader Mode مع اكتشاف التقنيات التي يعلنها الهاتف والوسم، مثل NfcA وNfcB وNfcF وNfcV وIsoDep وNfcBarcode.
- عرض خصائص عامة متاحة مثل ATQA وSAK وخصائص ISO-DEP وNFC-V، ومعلومات نوع/حجم MIFARE عندما يقدمها Android.
- قراءة سجلات NDEF العادية وعرض النصوص والروابط وأنواع المحتوى العامة، بحد أقصى 20 سجلًا في الفحص الواحد.
- سجل محلي لآخر 20 فحصًا؛ لا يخزن UID أو محتوى رسائل NDEF.
- إعداد الاهتزاز، معلومات الجهاز، ودليل تقنيات NFC.
- نسخ أو مشاركة تقرير تشخيص يضم تفاصيل التقنية العامة دون UID أو محتوى NDEF.

## البناء والتثبيت
1. افتح تبويب Actions في مستودع CardMaster.
2. افتح أحدث عملية Android debug build بعد اكتمالها بنجاح.
3. نزّل artifact باسم `cardmaster-android-debug`.
4. فك ZIP وثبّت `app-debug.apk` على هاتف Android.

الحد الأدنى Android 6.0 (API 23). يلزم هاتف يدعم NFC لاختبار القراءة الفعلية.

## حدود القراءة والخصوصية
- ظهور تقنية مثل IsoDep أو MIFARE لا يعني أن محتوى البطاقة متاح.
- التطبيق يقرأ NDEF العادي فقط عبر واجهة Android NDEF؛ لا يرسل أوامر APDU أو أوامر خاصة بالعدادات، ولا يقرأ قطاعات محمية أو مفاتيح أو أرصدة أو بيانات دفع.
- بطاقات الكهرباء قد تستخدم تطبيقًا أو بروتوكولًا مغلقًا أو بيانات محمية؛ يمكن عرض معلومات التعريف العامة فقط عندما يتيحها النظام.
- لا يتم حفظ UID أو محتوى البطاقة أو رفعه إلى الإنترنت.
