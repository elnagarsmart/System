# CardMaster – كارد ماستر

مشروع مستقل لإدارة وقراءة وسوم NFC العادية التي يملكها المستخدم أو لديه تصريح بإدارتها.

## الحالة الحالية
- واجهة ويب عربية أولية (RTL).
- يعمل دون قاعدة بيانات أو خدمة مدفوعة.
- قراءة وكتابة سجلات NDEF العادية عبر Web NFC في المتصفحات والأجهزة المدعومة.
- لا يقرأ أسرار أو بيانات الدفع من البطاقات البنكية، ولا ينسخها أو يعدّلها.
- لا يدعم تعديل بيانات بطاقات الهوية أو الدخول أو العدادات أو تجاوز الحماية.

## التشغيل
افتح `index.html` عبر خادم محلي أو استضافة HTTPS. Web NFC يتطلب سياقًا آمنًا (HTTPS أو localhost) ومتصفحًا/جهازًا متوافقًا، وغالبًا يعمل على Android Chrome. دعم NFC في متصفحات Windows محدود؛ قد تحتاج إلى قارئ NFC متوافق وبرنامج سطح مكتب منفصل.

## الخصوصية
النسخة الأولية تحفظ السجلات محليًا في المتصفح فقط. لا توجد قاعدة بيانات أو مزامنة سحابية حاليًا.

## خطة التطوير
1. اختبار التوافق الفعلي مع الهاتف والوسوم.
2. إضافة سجل محلي وإدارة الوسوم.
3. تقييم قارئ Windows المناسب قبل بناء تكامل سطح المكتب.
4. إضافة مزامنة اختيارية فقط بعد اختيار خدمة مجانية بحدود واضحة وموافقة المستخدم.
