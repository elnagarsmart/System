# CardMaster Professional — كارد ماستر

مشروع مستقل تمامًا عن Academia، يوفّر أدوات قراءة وتشخيص وإدارة وسوم NFC العادية والبطاقات المتوافقة، مع اختلاف القدرات حسب الجهاز والقارئ ونوع البطاقة.

## المنصات

### الويب / PWA
- واجهة عربية RTL متجاوبة للهاتف والكمبيوتر.
- تشخيص المتصفح والاتصال الآمن ودعم Web NFC.
- قراءة سجلات NDEF وبيانات النص والرابط والبيانات الثنائية العامة.
- كتابة سجل نصي NDEF على الوسوم العادية المتوافقة والقابلة للكتابة.
- سجل محلي وإدارة سجلات ونسخ احتياطي JSON واستيراده.
- التخزين والإعدادات داخل المتصفح فقط، دون قاعدة بيانات أو خدمة مدفوعة.

### Android
- تطبيق أصلي يستخدم Android NFC Reader Mode.
- يكتشف التقنيات التي يعلنها كل من نظام الهاتف والوسم، مثل NFC-A وNFC-B وNFC-F وNFC-V وISO-DEP وNFC Barcode عند إتاحتها.
- يعرض خصائص الاتصال العامة وخصائص MIFARE التي يعلنها النظام.
- يقرأ سجلات NDEF العادية ويعرض الأنواع المدعومة.
- سجل محلي لملخص الفحص دون UID أو محتوى سجلات NDEF.
- تقارير تشخيص ومشاركة، وإعداد الاهتزاز ومعلومات الجهاز.

### Windows
- تطبيق WPF مستقل لويندوز x64.
- تعداد قارئات PC/SC وفحص حالة وجود البطاقة.
- عرض ATR وبروتوكول الاتصال وطول ATR ووقت الفحص.
- سجل محلي للجلسة وتصدير/نسخ تقرير تشخيص TXT.
- لا يرسل أوامر إلى محتوى البطاقة ولا يعرض بيانات محمية.

## حدود التوافق
- لا يوجد قارئ واحد أو API يدعم كل البطاقات في العالم.
- Web NFC يقرأ NDEF فقط وفي المتصفحات والأجهزة الداعمة، وغالبًا Android Chrome عبر HTTPS.
- Android Reader Mode يكشف فقط التقنيات التي يعلنها النظام والعتاد والوسم؛ اكتشاف التقنية لا يعني أن محتوى البطاقة متاح.
- قارئ Smart Card المدمج في الكمبيوتر قد يكون تلامسيًا فقط وليس NFC لاسلكيًا. يحتاج الكمبيوتر إلى قارئ NFC لاسلكي متوافق مع PC/SC لاكتشاف وسوم NFC عبر هذه الواجهة.
- بعض بطاقات الدفع والهوية والدخول والمرافق تستخدم تطبيقات أو بيانات محمية؛ لا يحاول CardMaster تجاوز الحماية أو تعديل الأرصدة أو نسخ بيانات الاعتماد.

## الخصوصية
- لا تستخدم قاعدة بيانات أو خدمة سحابية في الإصدارات الحالية.
- بيانات سجل الويب تحفظ في Local Storage بالمتصفح.
- سجل Android يحفظ ملخصات تقنية عامة محليًا ولا يخزن UID أو محتوى NDEF.
- سجل Windows موجود في الذاكرة خلال الجلسة ويمكن تصدير تقرير عام يدويًا.
- لا تضع كلمات مرور أو أرقام بطاقات أو معلومات شخصية في السجلات.

## البناء
- Android: افتح تبويب Actions وشغّل/انتظر Android debug build، ثم نزّل artifact باسم `cardmaster-android-debug`.
- Windows: GitHub Actions ينشر ملف التطبيق داخل artifact باسم `cardmaster-windows-x64`.
- Web: ملفات ثابتة؛ افتح `index.html` عبر HTTPS أو localhost. يمكن استضافة الموقع على خدمة static hosting مجانية.

## الاختبار
نجاح البناء يؤكد أن المصدر قابل للبناء في بيئة CI فقط. يلزم اختبار Android على هاتف فعلي، وWindows على قارئ PC/SC فعلي، والويب على متصفح يدعم Web NFC قبل اعتماد كل ميزة نهائيًا.
