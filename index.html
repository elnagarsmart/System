حدود القراءة وحماية البيانات

Web NFC يدعم رسائل NDEF على الأجهزة والمتصفحات المتوافقة فقط. لا يعرض بيانات الدفع أو الأسرار أو أرصدة البطاقات البنكية أو بطاقات الهوية والدخول والعدادات، ولا ينسخ البطاقات المحمية أو يتجاوز الحماية. لا تدخل أرقام بطاقات أو كلمات مرور أو بيانات شخصية.

ملاحظات التوافق

على Android قد يعمل Web NFC في Chrome الرسمي عبر HTTPS. على Windows لا تتاح واجهة Web NFC عادةً؛ استخدم تطبيق CardMaster للكمبيوتر مع قارئ USB متوافق. قارئ Smart Card المدمج في بعض أجهزة HP قد يكون تلامسيًا وليس NFC لاسلكيًا.
